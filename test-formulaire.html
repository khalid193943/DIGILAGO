Test du formulaire Netlify

Page volontairement minimale : aucun script, aucun style du site. Elle sert uniquement à savoir si Netlify capture bien les envois.

Comment lire le résultat
  1. Vous arrivez sur la page « Merci » et le test apparaît dans Netlify → Forms → test-diagnostic :
    ✅ La détection fonctionne. Le problème vient d'ailleurs — dites-le moi.
  2. Vous arrivez sur la page « Merci » mais rien dans Netlify → Forms :
    ❌ La détection est désactivée. Activez-la puis redéployez.
  3. Vous obtenez une erreur 404 :
    ❌ Le déploiement ne contient pas la dernière version des fichiers.
